# Second Brain — Agent Contract (Karpathy LLM Wiki pattern)

This vault is a **personal second brain maintained by an LLM**. You (Claude) are the *librarian*:
the human curates **what** goes in; **you** build and maintain the knowledge base.

Implementation idea: Andrej Karpathy's "LLM Wiki" — raw immutable sources in `raw/`, an LLM-maintained
`wiki/` of interlinked markdown. No RAG, no embeddings, no proprietary schema: plain markdown that fits in
a long-context window and is auditable by a human in Obsidian.

## Scope of this brain
General-purpose: **work** topics, **behavior / performance / productivity** studies, **articles**, and
personal **notes & ideas**. Wiki content is written in **English** (technical terms stay in English even
when a source is in Portuguese).

## Folder map
```
raw/                 # immutable source material — READ ONLY, never edit or move these
  inbox.md           # quick fleeting capture (append on top); drained by /process-inbox
  assets/            # images/attachments belonging to sources
wiki/                # everything here is written and maintained BY YOU
  sources/           # one summary page per ingested source (cites original path/URL)
  entities/          # people, companies, products, tools
  concepts/          # ideas, frameworks, techniques, definitions
  synthesis/         # cross-cutting analyses, comparisons, themes
  index.md           # master catalog / map of content — keep current
  log.md             # APPEND-ONLY operation log — never rewrite past entries
output/              # answers/reports generated by /query
review/              # LEARNING LAYER — spaced-repetition state
  queue.md           #   the card deck (Q/A + Leitner box + due session) — you maintain this
```
The legacy folders `0 Notebook/`, `1 Books&Courses/`, `2 Files/`, `3 Templates/` and their notes are
**source material too**: read them, ingest them, but never modify them.

## Hard rules
1. **Never edit, move, or delete** anything in `raw/` or in the legacy `0–3` folders. They are the source of truth.
2. **Every wiki page cites its source(s)** in a `## Source(s)` section at the bottom (relative path or URL).
3. Connect pages with `[[wikilink]]`. If a linked page does not exist yet, create a stub for it.
4. After any change: **update `wiki/index.md`** and **append one entry to `wiki/log.md`** (date, operation, source, pages touched). Never rewrite the log.
5. On conflict with existing content, **flag it** under a `## Contradictions` section on the page — do not silently overwrite the old claim.
6. Plain markdown only. Optional lightweight frontmatter (`type:`, `source:`) is allowed for future Dataview use, but never required.
7. **Portability:** use vault-relative paths with `/` separators. Do not assume macOS or Windows. Do not invent shell scripts inside wiki pages.

## Slug & page conventions
- Filenames: lowercase, words separated by `-` (e.g. `wiki/concepts/big-o-notation.md`).
- Page shape: `# Title` → short summary → body sections → `## Related` (wikilinks) → `## Source(s)`.

## Learning layer (study pipeline)
This brain is also a **study machine**, built on learning science: active recall, spaced repetition,
interleaving, and elaboration (Feynman). Mechanics:

- **Recall cards live on the page.** Every `concepts/` and `synthesis/` page should end with a `## Recall`
  section: 2–5 question→answer pairs that test understanding (not trivia).
- **Scheduling lives in `review/queue.md`** as one block per card. Format:
  ```
  ## Card: <slug>
  - page: [[page-name]]
  - box: <1-5>
  - due: <session number>
  - Q: <question>
  - A: <answer>
  ```
- **Leitner boxes** = intervals in *sessions* (not calendar days — scripts have no reliable date):
  box 1→due in 1, 2→2, 3→4, 4→8, 5→16 sessions. Correct answer = box +1 (max 5); wrong = back to box 1.
- A **`session:` counter** is kept at the top of `review/queue.md`. `/study` increments it once per run,
  reviews every card with `due <= session`, grades the user's answer against `A`, and rewrites `box`/`due`.
- When `/ingest` or `/process-inbox` create/expand a page, they also add its `## Recall` cards to `review/queue.md`
  at `box: 1, due: <current session>`.

## Commands available
- `/ingest <path-or-URL>` — ingest a source; also writes `## Recall` cards and enqueues them.
- `/process-inbox` — triage `raw/inbox.md` items into the wiki (same recall treatment).
- `/query <question>` — answer from the wiki, save to `output/`.
- `/lint` — health check (broken links, orphans, missing citations, contradictions, index gaps).
- `/study` — run a spaced-repetition session (interleaved across topics).
- `/gaps` — learning health check: shallow/stub pages, pages without `## Recall`, frequently-missed cards → study plan.
- `/explain <concept>` — Feynman mode: user explains, Claude grades and patches gaps, may add recall cards.
