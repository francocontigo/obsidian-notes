# Source: Estrutura de Dados e Algoritmos (Augusto Galego)

Study notes on data structures and algorithmic complexity, by [[augusto-galego]].

## Summary
Covers asymptotic complexity ([[big-o-notation]]) and the core data structures with their read/insert/delete
costs: [[array]], [[linked-list]], [[queue]], [[hash-map]], [[stack]], [[binary-tree]], heap, graphs, and trie.

## Key takeaways
- Big-O measures **scaling** with input size (time and space), not raw performance.
- Common classes, fastest → slowest: O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ), O(n!).
- Array read is O(1) (contiguous memory); [[linked-list]] read/insert/delete is O(1) best, O(n) worst.
- [[queue]] = FIFO; [[stack]] = LIFO; [[hash-map]] = Python `dict` (hash function, load factor, collisions).
