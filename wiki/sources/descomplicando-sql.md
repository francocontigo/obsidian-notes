# Source: Descomplicando SQL (Day 2)

Course notes on SQL fundamentals, tagged for [[sql]] and [[databricks]].

## Summary
Introduces the building blocks of [[sql-language-elements]] (commands, clauses, expressions, predicates,
queries), the basic [[sql-data-types]], and database integrity mechanisms ([[database-integrity]]:
primary/foreign keys, constraints, sequences). Notes that dates follow `year-month-day` syntax.

## Key takeaways
- A SQL statement is composed of clauses; expressions produce scalar values / tables of rows & columns.
- Predicates evaluate to true / false / unknown.
- Constraints guarantee integrity but burden the DBMS, so they're used sparingly (most common: NOT NULL).
- Sequences provide continuity and uniqueness, typically used as identifiers.
