# SQL Data Types

Basic data types covered in the course.

| Kind | SQL type |
|---|---|
| Number | Int |
| Decimal | Float |
| Text | String |
| Boolean | Boolean |
| Date | Date |
| Date-time | Timestamp |
| Null | null |

Dates follow `year-month-day` syntax.
