# SQL Language Elements

The building blocks of a [[sql]] statement.

- **Commands** — produce a persistent effect on data/structures, or control transactions.
- **Clauses** — components of a command.
- **Expressions** — produce scalar values, or tables of rows and columns.
- **Predicates** — specify conditions evaluated by logic, returning true, false, or unknown.
- **Queries** — return data based on specific criteria.
