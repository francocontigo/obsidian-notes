# Linked List

A linear data structure of nodes linked by references (not contiguous memory like an [[array]]).

## Complexity ([[big-o-notation]])
- **Read** — best O(1), worst O(n).
- **Insert** — best O(1) (at head or tail), worst O(n) (must traverse).
- **Delete** — best O(1), worst O(n).
